# Class Up — CTP Siquirres

Demo visual de una plataforma de tutorías (prototipo, no tiene backend).

## Estructura
- `index.html` — todas las pantallas (login, inicio, chat, suscripción, perfiles, contenido, horario)
- `css/styles.css` — estilos
- `js/app.js` — navegación e interacciones de demostración
- `img/` — logo y foto

## Ver en local
Abrí `index.html` en el navegador. No necesita instalar nada.
